# OmniWorks Simulation Studio — Yoodli, Interviews and Certifications

**Simulation content is fictional.** These are original practice scenarios, not Yoodli-integrated sessions or official exam questions. Use this content as an instructor/learner prompt when setting up a Yoodli AI conversation; no API integration is configured.

## Standard session protocol
1. Select **scenario ID**, learner role, counterpart persona ID(s), difficulty and timebox.
2. Give the AI counterpart only its persona card, scenario context and hidden constraints. Do not disclose hidden information to the learner.
3. Start with the counterpart's opening challenge. The learner asks questions, makes recommendations and confirms next actions.
4. Evaluate using the common rubric below. Store sanitized feedback and improvements, not confidential real-client transcripts.

## Yoodli-ready copy/paste starter prompt
> You are **[fictional persona name, ID and designation]** at OmniWorks Industrial Systems Ltd., a fictional industrial enterprise. Conduct **[scenario ID]** with me as **[learner role]**. Stay in character. Start with one challenging opening question, ask realistic follow-ups, reveal details only if I elicit them, and challenge assumptions. Do not invent confirmed business facts beyond the provided case. After the role-play, score me against the rubric and give specific improvement actions. This is practice, not an official certification assessment.

## Scoring rubric (100 points)
| Dimension | Points | Evidence |
|---|---:|---|
| Discovery and active listening | 20 | Clarifies situation, asks follow-up questions |
| Business architecture and value thinking | 20 | Links goals, capabilities, value streams and outcomes |
| Requirements and evidence discipline | 20 | Separates facts, assumptions, constraints, NFRs and acceptance criteria |
| Trade-offs, risk and governance | 15 | Identifies options, decision rights, security/safety |
| Executive communication and stakeholder empathy | 15 | Concise, tailored, non-defensive |
| Closure and next steps | 10 | Summarizes agreements, owners and evidence requests |
