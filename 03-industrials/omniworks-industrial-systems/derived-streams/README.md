# Seven Derived Learning Streams — OmniWorks

**Architecture rule:** The [22-section master](../master/README.md) owns enterprise facts, strategic choices, value drivers, target outcomes and approved assumptions. Streams inherit those facts by stable master IDs and extend only domain-specific requirements, process details, architecture and simulations.
